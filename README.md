# LoadMargin — Freight Tools for Carriers

Smart spreadsheets and tools that help dispatchers and owner-operators make better load decisions before they accept a freight offer.

## Products

### Freight Profitability Dashboard PRO ($19)
Track profit, margin, and cost-per-mile per load. Know which loads are actually making money.
- Auto-calculates CPM, profit/mile, margin
- Historical tracking for 100+ loads  
- PROFITABLE / LOW MARGIN / LOSS verdict per load

### Load Selection Calculator ($12)
Decide if a load is worth taking before you accept it.
- Evaluate a load offer in under a minute
- Compare up to 5 loads side by side
- Accounts for deadhead miles and real costs

## Getting Started

### Deploy to GitHub Pages (Free)

1. Fork or clone this repo
2. Upload `index.html` to a new GitHub repo
3. Enable GitHub Pages in Settings
4. Visit `username.github.io/loadmargin`

### Deploy to GoDaddy

1. Log in to GoDaddy hosting panel
2. Open File Manager → public_html
3. Delete default index.html
4. Upload your index.html
5. Visit loadmargin.com
